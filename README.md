# EMG Controlled Prosthetic Hand

An EMG-controlled prosthetic hand developed as part of my MSc Electronics project.

## Overview
This project uses BioAmp Patchy EMG sensors to capture forearm muscle activity and classify hand gestures using Machine Learning. The classified gestures are used to control a prosthetic hand in real time.

## Features
- EMG signal acquisition
- Real-time gesture classification
- Random Forest classifier
- Arduino-based control
- Servo motor actuation
- Tkinter GUI for visualization

## Technologies Used
- Python
- Scikit-Learn
- Arduino Uno
- BioAmp Patchy
- Tkinter
